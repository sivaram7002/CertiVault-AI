### Role & Objective
Build a complete, responsive, dark-themed web application called **"CertiVault AI"**—a Course & Internship Certificate Vault with AI-powered metadata extraction and forensic fraud detection.

### Tech Stack
- **Frontend:** React (Vite or Next.js), Tailwind CSS, Lucide React icons.
- **Storage & Database:** Firebase (Firestore + Firebase Storage) OR IndexedDB/LocalStorage fallback so the app works immediately out of the box.
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`) using multimodal input (inline Base64 PDF/Image data) and structured JSON output (`responseSchema`).

### Core Features & Workflow

#### 1. Certificate Upload & Storage
- Support drag-and-drop and file selection for `.pdf`, `.png`, and `.jpg` files.
- Provide an optional field for an external verification URL or Google Drive link.
- Store the uploaded PDF/image file and its extracted metadata so users can view, search, filter, and download their certificates anytime.

#### 2. Automatic AI Metadata Extraction (On File Upload)
As soon as a user selects/drops a certificate file, convert it to Base64 and send it to the Gemini API to automatically extract and auto-fill the form with the following fields:
- **Student Name:** Full name of the recipient who completed the course.
- **Platform / Issuing Organization:** (e.g., NPTEL, Coursera, SkillRack, Udemy, HackerRank, edX, or internship company).
- **Course / Internship Title:** Name of the completed program.
- **Total Duration:** Extracted hours, weeks, or calculated duration between start and end dates (e.g., "8 Weeks", "40 Hours", "2 Weeks (10 Jun - 24 Jun)").
- **Completion / Issue Date:** Date of issuance.
- **Credential ID / Certificate Number:** Unique identifier or verification code if present.
- **Category:** Auto-classify into *Course*, *Internship*, *Coding / Hackathon*, or *Workshop*.
- **Skills:** Array of 3–5 relevant technical/domain skills inferred from the certificate.

#### 3. AI Forensic Fraud & Authenticity Check
During the same AI analysis pass, inspect the certificate for visual and structural authenticity and return:
- **Authenticity Status:** One of `"Verified Authentic"`, `"Suspicious / Needs Review"`, or `"Potentially Fraudulent"`.
- **Trust Score:** Integer from `0` to `100`.
- **Forensic Reasoning Summary:** A concise explanation of why the certificate received its score.
- **Forensic Checklist (Pass / Warning / Fail for each):**
  1. *Typography & Alignment:* Check if the student name or dates use mismatched fonts, irregular kerning, or misaligned baselines compared to the template (signs of text overlay/editing).
  2. *Logos, Seals & Signatures:* Check for official issuer branding, authorized signatures, or emblems.
  3. *Credential & Verification Markers:* Check for valid-looking certificate IDs, QR codes, or verification URLs.
  4. *Visual Integrity:* Check for pixelation artifacts, different background color boxes around edited text, or unnatural compression around the name/duration fields.

#### 4. Dashboard, Filtering & Built-in PDF/Document Viewer
- **Summary Stats Bar:** Display total certificates, total verified authentic count, unique platforms count, and fraud/suspicious alerts count.
- **Search & Filter:** Filter by category (*All, Courses, Internships, Coding*), authenticity status (*All, Verified, Suspicious/Fraud*), and a live search bar (searching by course title, student name, platform, or skills).
- **Certificate Cards:** Display the course title, platform badge, student name, total durationbadge, authenticity status pill with Trust Score, and skill tags.
- **Interactive Inspection Modal:** Clicking a card opens a split-screen modal:
  - **Left side:** Embedded PDF/Image previewer with zoom/open-in-new-tab and one-click download.
  - **Right side:** Full extracted metadata (Student Name, Platform, Duration, Credential ID) and the complete AI Forensic Verification Report with the Trust Score gauge and individual check statuses.

### UI/UX Design Guidelines
- Use a modern dark slate/indigo theme (`bg-slate-950`, glassmorphism cards, subtle borders).
- Use clear color-coding for authenticity states: Emerald Green for *Verified Authentic*, Amber for *Suspicious / Needs Review*, and Rose Red for *Potentially Fraudulent*.
- Include an interactive "Re-Scan with AI" button inside the upload modal and allow manual editing of any AI-extracted field before saving to the vault.
